1、工程基于Visual studio 2015，只配置64位程序
2、使用的OpenCV版本为4.9.0
3、在编译和运行Debug前，需要在Bin文件夹放置opencv_world490d.dll，Include文件夹放置opencv2头文件夹，Depends文件夹放置opencv_world490d.lib
4、在编译和运行Release前，需要在Bin文件夹放置opencv_world490.dll，Include文件夹放置opencv2头文件夹，Depends文件夹放置opencv_world490.lib	


1. The project is based on Visual Studio 2015 and only configured with 64 bit programs
2. The OpenCV version used is 4.9.0
3. Before compiling and running Debug, it is necessary to place opencv_world490d.dll in the Bin folder, opencv2 header folder in the Include folder, and opencv_world490d.lib in the Depends folder
4. Before compiling and running Release, it is necessary to place opencv_world490.dll in the Bin folder, opencv2 header folder in the Include folder, and opencv_world490.lib in the Depends folder
